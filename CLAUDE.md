# EB Mail Playbook · Projektanweisungen

Dieses Repo ist das komplette Wissen für Essentialbag-Kampagnen-Mails (Figma → Klaviyo). Antworten auf Deutsch, kurz, ohne Fachjargon.

1. Bei jeder Mail-, Hero-, Mockup- oder Klaviyo-Aufgabe den Skill **`eb-mail-produktion`** nutzen (`skill/eb-mail-produktion/SKILL.md`). Neue Session/neuer Account: zuerst dessen Preflight.
2. Verbindliche Regeln: [`LEARNINGS.md`](LEARNINGS.md) (A–L aktueller Workflow, M–T frühere Projekte) und `skill/eb-mail-produktion/references/regeln-design-copy.md`.
3. Eigene Brand-Daten, Kampagnen und Bild-Assets sind nicht Teil dieses öffentlichen Repos (siehe README „Eigene Daten ergänzen“).
4. Nie: Klaviyo-Key ausgeben, Templates überschreiben, geplante/gesendete Kampagnen ändern, ohne OK senden/veröffentlichen.
5. Neue Erkenntnisse am Ende einer Session in LEARNINGS.md + Skill-Referenzen + CHANGELOG festhalten.
